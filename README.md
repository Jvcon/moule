# Moule

个人可复用的开发环境 playbook —— 围绕 **devcontainer + mise** 的脚手架。

从 catalog 里「à la carte」点选语言与工具，生成/更新项目的 `.mise.toml` + `.devcontainer/`。

## 定位

- 站 `mise generate devcontainer` 肩膀上：devcontainer 底座复用官方命令，只做「选型 + 策略 + catalog」这一层。
- 四层 overlay catalog：`built-in` / `bucket` / `global` / `project`。
- 先纯确定性，AI 调研顾问后置。

## 命名

Moule（法语「模具」）—— cookiecutter 式隐喻：压出一样的环境（双关：法语里也是「青口/贻贝」）。
